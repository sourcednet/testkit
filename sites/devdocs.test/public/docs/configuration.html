Configuring Tidemark

Tidemark reads its settings from tidemark.toml in the watched directory. Every setting has a default, so the file is optional. Settings given on the command line override the file.

Settings

SettingDefaultMeaning
interval1hHow often a running watcher rescans
ignore.git, node_modulesPaths never checksummed
algorithmsha256Checksum algorithm: sha256 or blake3
reporttextReport format: text or json

Example

interval = "30m"
ignore = [".git", "build", "*.tmp"]
algorithm = "blake3"
report = "json"

Changes to the file take effect on the next scan. There is no need to restart a running watcher.
